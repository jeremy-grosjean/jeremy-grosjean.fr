Déclaration d'accessibilité

Engagement

Ce site personnel n'est pas soumis à l'obligation légale d'accessibilité (RGAA), mais je veux qu'il soit utilisable par tout le monde. L'objectif est le niveau AA des règles internationales WCAG 2.2.

État de conformité

Le site n'a pas fait l'objet d'un audit officiel. Par prudence, il est déclaré « partiellement conforme ».

Ce qui a été vérifié

Score d'accessibilité Lighthouse (Google PageSpeed) : 100/100, sur mobile et sur ordinateur.

Tout se fait au clavier : Tab pour avancer, Échap pour fermer, Ctrl + K pour le terminal, ? pour la liste des raccourcis.

Contrastes des textes vérifiés, avec un mode « contraste renforcé », une taille de texte réglable et un espacement de lecture.

Les animations s'arrêtent si votre appareil demande de réduire les animations.

La langue de chaque page est déclarée (6 langues), pour que les lecteurs d'écran prononcent correctement.

Les fenêtres sont annoncées aux lecteurs d'écran par leur rôle et leur titre ; l'animation de fond, décorative, leur est masquée.

Une version sur une page, sans animation, est disponible : jeremy-grosjean.fr/#recruteur.

Limites connues

Le jeu « Protéger le serveur » demande des gestes rapides. Les jeux de support N1 et N2, au tour par tour, sont une alternative sans limite de temps.

Le site n'a pas encore été testé avec tous les lecteurs d'écran.

Signaler un problème

Si un contenu vous est inaccessible, écrivez-moi à contact [at] jeremy-grosjean.fr : je vous répondrai et vous donnerai l'information sous une autre forme.

Déclaration établie le 28 octobre 2026.
